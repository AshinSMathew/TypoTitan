# Typo-Titan

**This is a cyber typing challenge competition to check cyber command typing speed. Anyone who wants to participate can log in to the page and join room code NYGDDX.**

## Project Overview

Typo-Titan is an advanced typing competition platform specifically designed to measure and improve proficiency in typing cyber commands. The application provides a rigorous environment for users to test their speed and accuracy against various technical commands. 

The competition consists of 25 questions to be completed within a 15-minute time limit. Upon completion of the challenge, participants will be provided with their final rank.

## Features

*   **Real-time Typing Metrics:** Accurately calculates words per minute (WPM) and accuracy percentages.
*   **Specialized Content:** Focuses exclusively on cyber commands and technical syntax.
*   **Multiplayer Rooms:** Allows users to join specific rooms (such as NYGDDX) to compete against peers.
*   **Time-Restricted Challenge:** Challenges participants with 25 questions within a strict 15-minute timeframe.
*   **Competitive Ranking:** Displays a final rank at the end of the session based on performance.
*   **Performance Tracking:** Records user progress and high scores over time.
